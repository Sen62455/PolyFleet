# 控制台运维效率改进

## 实施计划

以现有节点和资产接口为基础，完成以下四项功能。前端沿用云帆主题、统计卡、状态标签和表单规范，支持明亮、暗黑、护眼及窄屏布局。

1. 资产与续费：集中查看 VPS 档案，按到期日期排序，筛选已过期、7 / 30 天内到期、未设置日期的节点，复用资产编辑入口。
2. 数据导出：导出筛选后的资产清单 CSV、未来续费日期日历，以及流量报表的每日用量和当前排行 CSV。
3. 快速跳转：通过 `Ctrl/Cmd + K` 搜索控制台页面和节点名称、地址、供应商、地区，支持方向键与回车选择。
4. 页面链接：页面和节点详情保存在 URL 中，支持刷新恢复及浏览器前进、后退。

## 使用方式与边界

- 资产与续费位于侧边栏「管理」。统计卡对应全部节点；列表可叠加关键词、供应商、到期状态筛选。导出包含全部筛选结果，不限于当前分页。
- 到期状态按浏览器本地日历日期计算，到期当天显示「今天到期」。未登记日期表示未知，不表示永不过期。
- 自动续费是供应商侧设置的记录。修改档案不会触发付款或调整服务器配置。
- 续费日历只包含筛选结果中今天及以后的到期日期，为一次性全天事件，附带提前 7 天提醒。导入常用日历后由日历应用提醒；日历文件不会随控制台后续修改自动同步。
- CSV 使用 UTF-8 BOM，保留中文并转义引号、逗号、换行。可编辑文本中的电子表格公式前缀会被转为文本。
- 流量导出按已成功加载的报表范围生成，带统计起止时间和原始字节数。「排行」仅包含接口返回的当前榜单，并非全部用户或节点明细。
- 页面链接示例：`#/assets`、`#/reports`、`#/nodes/example-node?from=assets`。打开链接仍需登录；链接不包含凭据。
