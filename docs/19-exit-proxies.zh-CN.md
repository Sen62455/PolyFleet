# 出口代理（链式出口）

管理员可以给入口节点选择是否再挂一条出口。出口可以是租来的 Proxy IP，也可以是
另一台落地 VPS。未配置时行为与现在相同：用户连到哪台节点，就从那台节点的公网 IP
出网。

## 流量怎么走

出口提供两种模式。默认沿用客户端链式连接；已在入口服务器配置出口时，可开启
「入口服务器转发」。面板开关负责订阅表达，不会自动安装或修改入口服务器配置。

用户仍然只连接 PolyFleet 管理的入口节点（Hysteria2 或 VLESS/Reality）。Clash Meta
和 sing-box 订阅把入口当作前置（`dialer-proxy` / `detour`），再连接到出口的
SOCKS5 或 HTTP 代理。网站看到的是出口 IP，不是入口 VPS IP。

客户端链式模式下，URI / Base64 订阅不能表达链式出口，仍然直连入口。

服务器转发模式下，入口核心连接落地代理，再连接网站。SOCKS5 协商在入口和落地
之间完成，减少客户端到海外的串行往返。订阅仅输出入口协议，名称保留
「入口节点名 · 出口名」；Clash、sing-box、URI、Base64 都可使用，不向客户端分发
落地代理凭据。入口上的路由应在落地不可用时失败，不能悄悄回退到入口直出。

原生 Hysteria2 可在 `/etc/hysteria/config.yaml` 配置 SOCKS5 outbound；落地机指引
提供配置片段。先备份并合并配置，保留认证、证书、统计，核对已有 ACL，再验证出口
和 UDP。确认服务器转发正常后开启面板开关。修改出口地址、密码或节点绑定时，需
同步入口配置；解除绑定或删除面板记录也不会自动恢复服务器直出。

出口配置只存在于控制面，不会改写节点上的 Hysteria2 / sing-box 核心配置，也不要求
给落地机安装 Agent。

## 延迟与速度

Clash 订阅默认输出 `unified-delay: false`，URL 测试包含本次建立网站连接与请求的
耗时。客户端全局或合并配置可能覆盖订阅，需核对实际运行值。开启统一延迟会消除
部分握手影响，适合比较 RTT，但不等于首次打开网页的耗时。

完整路径应从实际客户端测试，并验证出口 IP。新建网站连接、已有连接复用、底层
代理隧道冷启动的结果不同。HTTPS 首字节还不包含整个网页的图片、脚本下载和渲染；
下载吞吐量应另以 Mbps 或 MiB/s 测量，不能由毫秒数推断。

## 控制台

1. 打开「出口代理」。
2. 选择「不使用」以外的类型：
   - **租用 Proxy IP**：填写服务商给的主机、端口、协议和账号。
   - **落地 VPS**：填写落地机将要监听的地址，保存后打开「落地机指引」。
3. 把出口挂到一台或多台入口节点。也可在节点编辑页的「链式出口」里选择。

落地机指引包含 sing-box mixed inbound 安装脚本、只放行入口 IP 的防火墙命令，以及从
入口节点验证出口 IP 的 `curl`。落地机不要再安装 PolyFleet Agent，也不要让终端用户
直连它。

### 全新落地机按步骤配置

指引适用于 Debian / Ubuntu 的 amd64、arm64 服务器，前 5 步在落地机 root
终端执行。每个命令块整段复制，出现错误先修复，不要继续下一步。

1. 安装 curl、Python、nftables、nano 等依赖，下载并校验 sing-box 1.12.21。
2. 自动写入 `/etc/sing-box/polyfleet-landing.json`，内容已经带入面板中的代理
   端口和账号密码；已有文件自动备份，随后运行配置检查。
3. 为已绑定的入口解析 IP，写入 `/etc/nftables.d/polyfleet-landing.nft`，
   限制 TCP 代理端口和动态 UDP 端口的来源，并设置开机加载。未绑定入口时停止执行。
4. 写入 `/etc/systemd/system/polyfleet-landing.service`，以专用账户运行代理，
   依赖防火墙服务启动。正常结果为 `active` 和 `enabled`。
5. 检查服务、监听端口和防火墙。空闲时没有 UDP 监听属于正常现象。
6. 切换到已绑定的入口 VPS，执行指引中的 curl，比较入口 IP 和落地出口 IP。
7. 在电脑或手机更新 Clash / sing-box 订阅，选择“入口节点名 · 出口名”，验证网站
   看到的是落地出口 IP。
8. 后续用指引中的 nano 命令修改配置，校验后重启；新增入口、入口 IP 或代理端口
   变化时重新生成并执行防火墙步骤。面板修改不会自动同步落地机文件。

每步均显示执行位置、涉及的文件和成功标志。生成的指引含真实代理密码，请勿公开分享。

## 接口

- `GET/POST /api/v1/exit-proxies`
- `GET/PUT/DELETE /api/v1/exit-proxies/{id}`
- `PUT /api/v1/exit-proxies/{id}/nodes`
- `GET /api/v1/exit-proxies/{id}/landing-guide`（仅落地 VPS；含解密后的安装凭据）

密码使用与用户凭据相同的 master key 封装，列表接口不返回明文。创建落地出口时若未
填写密码，控制面会生成随机密码。

`server_side` 为布尔字段，创建时默认 false；更新时省略该字段保留原值。
